# Deutsch Balloons — A1 to C2

A standalone HTML5 German vocabulary balloon game.

- 500 stages
- 10 substages per stage (5,000 total)
- Progression: A1 → A2 → B1 → B2 → C1 → C2
- Large, shaded balloons
- Touch/drag controls and keyboard controls
- Built-in first-page tutorial
- No external libraries required

## GitHub Pages
Upload `index.html` to the repository root and enable GitHub Pages from the `main` branch/root.
