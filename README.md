# Deutsch-PANG — 60 Stage Arcade Prototype

A Pang-style German-learning arcade game, redesigned from the original single-page prototype.

## Current build
- 60 stages: 10 each A1, A2, B1, B2, C1, C2
- Direct selection of any CEFR level
- Stage progress saved separately per CEFR level
- 60 German locations with country flag in the HUD
- Pang-inspired bouncing/splitting-ball mechanics
- German prompts with spoken German on hit
- Vocabulary mastery tracking in localStorage
- Mobile touch controls + keyboard controls
- No build step

## Future expansion
The stage data is deliberately separated from the game engine so the 60-stage prototype can be expanded toward 5,000+ stages and additional German-speaking countries.
